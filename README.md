# Xiaoxing Chen · Portfolio

Personal portfolio site, live at **https://kevinlionel874.github.io**.

- Plain HTML, CSS and JavaScript, no build step. Hosted on GitHub Pages.
- Sections: intro, about, skills, projects (F1 Compass, Study Tracker) and contact.
- Styled like a component datasheet: sections are numbered as pins, labels use a monospace font.
- The band-gap picker in the intro recolors the site with the LED you choose and shows that color's photon energy (E = hc/λ).
- Light and dark themes (follows the system setting, with a toggle), responsive layout down to phone widths, keyboard accessible.

To preview locally, open `index.html` in a browser.
